# translator - SuhbatDosh AI 🎙️

SuhbatDosh AI — Jonli og'zaki suhbatlar va tanishuvlar uchun aqlli teleprompter (Smart Speech Teleprompter).

## Xususiyatlari
- 🔇 **100% Tovushsiz rejim (Silent Teleprompter):** Suhbatdosh hech qachon telefon gapirayotganini eshitmaydi.
- 🎯 **Doimiy boshlang'ich gap (Icebreaker):** Ekranda doimiy turuvchi kalit gap.
- 💬 **Suhbatni ulovchi mantiq:** Har bir javob ortidan muloqotni qizdiruvchi savol beriladi.
- 🇺🇿 **100% O'zbekcha tarjima:** Har bir ruscha gapning tagida aniq o'zbekcha ma'nosi aks etadi.
- 🎭 **Dinamik Hazillar:** Suhbat mavzusiga qarab o'zgaruvchi hazil rejimi.
- 📱 **Mobile-First Shazam dizayni:** Telefon ekrani uchun skrollsiz (`100dvh`) ixcham dizayn.

## Texnologiyalar
- React 18
- Vite
- Tailwind CSS
- Lucide React
- Web Speech Recognition API

## O'rnatish va Ishga tushirish
```bash
npm install
npm run dev
```
